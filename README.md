# Veterinaria

Proyecto web desarrollado como parte de la práctica de **Trabajo Colaborativo con Git y GitHub**.

## Integrantes

- Nestor Alejandro Mamani Condori
- Ariel Alvarez Mamani

## Descripción

Sitio web para una veterinaria que permite presentar información sobre sus servicios, conocer más sobre la veterinaria y solicitar una cita mediante un formulario.

El proyecto fue desarrollado de manera colaborativa utilizando Git y GitHub para gestionar ramas, commits, Pull Requests y la integración de cambios.

## Tecnologías

- HTML
- CSS
- JavaScript
- Git
- GitHub

## Funcionalidades

- Página principal de la veterinaria.
- Menú de navegación.
- Sección de servicios.
- Sección sobre la veterinaria.
- Sección de contacto.
- Formulario para solicitar citas.
- Validación del formulario con JavaScript.
- Mensajes interactivos para el usuario.
- Diseño adaptable a diferentes tamaños de pantalla.

## Estructura del proyecto

- `index.html` — Estructura y contenido del sitio.
- `style.css` — Diseño y estilos visuales.
- `script.js` — Funcionalidades e interacciones.
- `README.md` — Información general del proyecto.

## Trabajo colaborativo

El proyecto utiliza diferentes ramas de Git para desarrollar funcionalidades de manera independiente.

Los cambios realizados por cada integrante son enviados a GitHub y posteriormente integrados a la rama `main` mediante Pull Requests y revisión de código.
